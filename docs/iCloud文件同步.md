# 普通 iCloud 账号的文件同步

不需要 Apple 开发者账号。软件通过 Windows 版 iCloud 管理的云盘文件夹交换文件，不读取 Apple 账号密码，也不使用私人网页接口。

## 连接步骤

1. 在电脑打开 Windows 版 iCloud，登录自己的 Apple 账户。
2. 打开「iCloud 云盘」，完成设置。不要把「iCloud 照片」当作云盘。
3. 回到清研「数据与设置 → iCloud 文件同步」，点击「重新检测」。也可填写 Windows 版 iCloud 显示的自定义云盘位置。
4. 点击「连接并启用同步」。软件会在该云盘目录中建立「清研复习」。

如果还未开启云盘，软件保持本地使用，不会创建一个假云盘目录，也不会迁走现有数据。

## 文件如何存储

```text
iCloud 云盘/
  清研复习/
    资料附件/<附件编号>/<原文件名>
    同步数据/device-<设备编号>.zip
    手机查看说明.txt
```

「同步数据」中的每台设备分别写自己的 ZIP，包含资料信息、错题、练习卷、成绩、设置、原始附件和删除标记。正在使用的 SQLite 数据库仍留在本机，不直接放进云盘同步。

保存记录后自动写入同步包；读取记录时检查其他设备的包，后台也定期检查。可以点击「立即写入云盘」或「从云盘更新」。只有新的、校验通过的同步包才会导入。iCloud 的实际上传、下载由 Apple 客户端完成，软件只能确认本机同步文件夹已经写入，不能确认 Apple 云端已收妥。

同一条记录以较新的修改时间为准；完全同时间、不同内容的冲突保留本机版本并提示。删除标记防止旧包让错题复活。手动导入旧完整备份恢复已删除记录，会作为一次新修改。每次读取新同步包之前都会在本机 `data/automatic-backups` 保存完整 ZIP，方便恢复。

不要同时在多个设备修改同一条记录。请先等 iCloud 显示同步完成，再切换设备。

## 手机上能做什么

在同一 Apple 账户的 iPhone 上，打开「文件 → iCloud 云盘 → 清研复习 → 资料附件」，可以直接查看已同步的原始 PDF、Word、文本和图片。附件副本不会被程序自动删除，以保留历史练习卷使用的题图。

在原生清研 App 中打开「数据与设置 → iCloud 文件同步」，选择和 Windows 端相同的云盘文件夹。同步包交换完成后可直接在手机或平板查看记录。已缓存的资料可离线打开。

「选择同步包更新」会应用包中较新的修改和删除，并先备份本机。「导入完整备份」仍保留现有同编号记录，只补充不存在的记录。

## 开发验证

```powershell
node desktop/build.mjs
node tests/icloud-sync.mjs
node tests/desktop-local.mjs
```

测试使用临时目录模拟两台设备，验证附件、更新、旧版本保护、删除传播、手动恢复、同时间冲突、自动写入、断开后的本地使用及稳定的设备编号。真实 iCloud 上传仍需在用户开启云盘后验证。

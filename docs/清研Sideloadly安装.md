# 清研：直接安装到 iPhone / iPad

当前使用 Sideloadly 直接安装清研，不需要先安装 AltStore。

## 首次安装

1. 用支持数据传输的线连接 iPhone 或 iPad，解锁设备，并在设备上确认“信任此电脑”。
2. 打开电脑上的 Sideloadly。
3. 在 iDevice 中选中目标 iPhone 或 iPad。若列表只显示 iPhone，请把数据线换接到 iPad，并确认 iPad 已解锁。
4. 点击左侧 IPA 图标，选择自己编译的清研 IPA 文件。更新时使用上次签名的 Apple 账户覆盖安装。
5. 自行填写 Apple 账户，点击 Start，在工具窗口中自行完成密码与验证码。
6. 等到工具明确显示 Done。报错时保留窗口，以日志中的具体错误继续处理。
7. 若手机提示“未受信任的开发者”，在“设置 → 通用 → VPN与设备管理”中自行信任本人的开发者账户。
8. 若提示需要开发者模式，在“设置 → 隐私与安全性 → 开发者模式”中自行开启，并按手机提示重启和确认。

## 每周续签

普通免费账户的签名有效期为 7 天。到期前连接设备，在 Sideloadly 中选择相同 IPA、使用同一 Apple 账户，再次点击 Start 完成覆盖安装。保持相同账户和应用标识；先同步/备份资料，不要先删除手机上的清研。

如需自动刷新，可在工具中按官方说明配置；当前以每周手动续签为准。签名有效期间，清研可在电脑关机时独立运行。

## 连接普通 iCloud 云盘

安装后在清研的同步界面选择云端文件夹，通过系统文件选择器选中“iCloud云盘 / 清研复习”。第一次同步需要联网；下载到本机的资料可离线打开。不同设备间的同步依赖 iCloud 实际完成上传与下载。

1.5.0 适用于 iOS 和 iPadOS 16 及以上，使用 Xcode 27 编译。iCloud 云盘和 GitHub 提供的是安装包文件，请从 Windows 的 Sideloadly 为连接的设备签名安装。

## 使用入口

- 数据与设置 → DeepSeek 解题。输入自己的 API Key。纯文字使用 V4 Pro，带题图使用 Flash。
- 左侧菜单 → AI 拍照搜题。在相机预览中框选题目，拍下后继续微调，也可以重拍。从相册选图也会直接进入框选窗口。点「使用选区」回到搜题页，再点「开始搜题」。
- AI 解析、错题详情和练习卷预览会排版标题、列表与数学公式。编辑解析时可在「编辑原文」和「预览排版」之间切换。
- 长解析会按屏幕宽度换行，超宽公式可单独横滑。出现输出上限提示时，点「继续生成」接着解答。
- 资料库 → 上传 / 扫描资料 → 智能扫描 PDF。可连续拍摄或从相册导入，逐页裁边、旋转、调序和选择滤镜。
- 扫描预览可调「去阴影」与「文字锐化」，点「校正」拖动四角拉正斜拍页面。
- 选择「生成 PDF」后设置纸张与清晰度。默认在设备上识别中英文并写入可搜索文字层。生成的文件回到资料表单，填写分类后保存到资料库或习题集文件夹。每份最多 40 页、20 MB。
- 资料库 → 习题集文件夹。可以创建文件夹，在上传或编辑练习时选择归属。
- 错题本 → 新增错题 → 从习题集中框选。选择练习和 PDF 页码，拖出范围并用四角调整，再保存题图。
- 左侧菜单 → AI 变式练习。选择一道错题生成同类型新题，再展开参考解析。错题详情也提供直达入口。

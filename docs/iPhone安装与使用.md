# 在 iPhone 独立运行清研（v1.0.1）

这是复用清研界面的手机本地运行版。安装后，界面资源、学习记录与已同步的附件保存在 iPhone。电脑关机、外出或没有 VPN 时可以打开；读取新的云端内容需要 iCloud 可联网。

需要安装来自 App Store 的免费应用 Scriptable（含可选赞赏购买，本方案不需要购买）。它提供手机本地界面运行和 iCloud 文件读写能力，不需要开发者账号或服务器。

若旧版本点击后出现空白，先完全退出 Scriptable，再将「手机安装/清研启动修复版.js」复制到 Scriptable 文件夹，点击新出现的「清研启动修复版」卡片。它使用原手机缓存，不需要卸载应用。v1.0.1 调整了启动与脚本通信方式，并加入可见的错误提示。

## 第一次安装

1. iPhone 在 App Store 安装 **Scriptable**，并先打开一次。官方链接：https://apps.apple.com/cn/app/scriptable/id1405459188 。
2. 在 iPhone 的「文件 → 浏览 → iCloud 云盘 → 清研复习 → 手机安装」找到 **清研.js**。
3. 长按「清研.js」选择「复制」，返回 iCloud 云盘，进入 **Scriptable** 文件夹，在空白处长按并粘贴。如果还看不到 Scriptable 文件夹，请确认手机允许 Scriptable 使用 iCloud 云盘并重新打开一次该应用；不要手工新建一个同名文件夹代替应用目录。
4. 回到 Scriptable，点击新出现的 **清研** 卡片运行，打开完整复习界面。第一次运行可先用手机本地模式。
5. 进入清研「数据与设置 → iCloud 文件同步 → 连接 iCloud 文件夹」，选择 **iCloud 云盘中的“清研复习”文件夹**，点「打开」。不要选「手机安装」或某个 ZIP 文件。然后点「同步更新」。

若文件还显示下载图标，请先联网等文件下载完成。文件夹中的 ZIP 是学习数据，不是应用入口；应用入口是 Scriptable 里的「清研」。请勿在 Safari 输入电脑上的 `127.0.0.1` 地址。

## 以后自动连接 iCloud

Scriptable → 设置 → **File Bookmarks（文件书签）** → 添加文件夹，选择同一个「清研复习」，名称填写 **清研复习**（完全一致）。

以后在 Scriptable 中运行「清研」会读取这个书签，尝试更新后仍使用手机缓存打开。未配置书签时，本地记录仍保留，下次运行需要重新选择云盘文件夹才能同步。手机本地记录保存在 Scriptable 的 QingyanMobile 文件夹；卸载 Scriptable 会影响本地缓存，请先导出完整备份。

## 放到手机主屏幕

在 iPhone「快捷指令」App 新建快捷指令，按顺序添加：

1. **URL**，填写 `scriptable:///run?scriptName=%E6%B8%85%E7%A0%94`。
2. **打开 URL**。

将快捷指令命名为「清研」，从快捷指令详情选择「添加到主屏幕」。这个入口会打开 Scriptable 并运行清研。不要使用在后台直接运行脚本的快捷指令动作：从 Scriptable 设置创建的文件书签只能在应用内使用。

## 日常使用

- 支持资料上传、错题归档、错题组卷、真题/模拟分开统计，与电脑版共用界面。
- 保存时先写入手机缓存，再尝试写入自己的 `同步数据/device-<设备编号>.zip`。联网后在设置中点「同步更新」可重试。程序打开、切换页面或回到前台时，也会在间隔达到一分钟后尝试更新；关闭应用后不持续执行脚本。
- 电脑和手机分别写自己的包，不直接共享正在使用的数据库。电脑下次运行时读取手机包。
- 离线可操作已下载的记录和附件；首次使用前需联网安装、同步。苹果实际上传进度以「文件」App 为准，“目录已写入”不等于云端已经接收。
- 切换设备前先等待 iCloud 同步完成。不要同时编辑两端同一条记录；同编号记录以修改时间较新的版本为准，完全同时间不同内容会保留本机并提示冲突。
- 手机当前限制：单文件 20 MB、附件累计 64 MB、单个同步包 64 MB。更大的资料库请使用电脑版；这是首版内存限制。
- Word 文档与完整备份通过 iOS 的“保存到文件”对话框导出，可选择 iCloud 云盘。练习卷需要打印时，在 WPS 或 Word 中打开导出的 DOCX。手机首版没有直接打印 PDF 按钮。

# 清研 · 考研复习工作台

第一版包含资料库、错题本、错题组卷和成绩分析。浏览器通过专属链接免登录使用，数据与原始文件保存在服务端。普通网址不展示个人资料，只有持有专属入口的人才能访问。示例预览不会保存到个人数据。

桌面「清研考研复习」快捷方式保存专属入口；首次打开后浏览器记住访问权限，之后可直接使用。清除浏览器 Cookie 或更换设备后，重新使用专属链接即可。请勿把快捷方式或专属链接转发给别人。

## 使用流程

1. 在「资料库」上传文件，选择科目，以及习题集、笔记、真题卷或模拟卷。支持 PDF、DOC/DOCX、TXT/Markdown、PNG/JPG/WebP 和 ZIP，单个文件最大 20 MB。可以打开、下载、修改资料信息。
2. 在「错题本」录入题干或上传题图，填写知识点、错因、难度和解析。可关联资料并添加标签，按科目、知识点、错因、掌握程度筛选。文字公式可用 Unicode；本版不含扫描识别与公式编辑器。
3. 勾选错题，进入「错题组卷」。支持跨科目组合、调整顺序与分值、设置答题留白、在文末附参考答案。Word 导出为真正的 `.docx`，图片会嵌入文档。PDF 使用预览中的浏览器打印功能。保存的练习卷包含独立题目快照，后续改题不影响旧卷。
4. 在「成绩分析」记录自评分数、满分、日期、用时和复盘。真题卷与模拟卷独立统计、不同颜色展示，可按科目、类型、日期筛选。得分率用于比较不同满分试卷；也可切换原始分数。
5. 在「数据与设置」自定义科目、备考目标与目标考试日期。日期由用户自行设置，不预设官方考试时间。

JSON 导出仅备份结构化记录和附件引用，原文件需单独下载；本版没有备份恢复功能。删除记录需确认，已保存练习卷的题目快照不会随源题删除。

## 本地运行

要求 Node.js >= 22.13、npm 和 Git。首次运行：

```powershell
npm ci --prefer-offline --no-audit --no-fund
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_complete_darkstar.sql
npm run dev -- --port 5173
```

免登录本地开发在被 Git 忽略的 `.dev.vars` 中设置 `STUDY_ACCESS_KEY`，开发测试值使用 `local-testing-device-access-not-a-production-secret`。然后打开 `http://127.0.0.1:5173/#access=local-testing-device-access-not-a-production-secret`。线上密钥由 Sites 的 secret 环境变量设置，不能写入源码或构建包。密钥不在浏览器日志、查询参数或引用来源中发送；页面会立即移除地址栏中的片段并换成 HttpOnly Cookie。

本地数据库与线上数据库相互独立，发布不会上传本地测试数据。SQL 只在首次初始化时执行；后续迁移按顺序应用，不重放已有表的创建 SQL。未配置 `STUDY_ACCESS_KEY` 时保留原账户登录方式用于兼容旧部署。

再次启动只需 `npm run dev -- --port 5173`。本地数据库与对象文件位于被 Git 忽略的 `.wrangler/state/`。不要清理这个目录，除非确定不需要本地记录。

## 验证

```powershell
npx tsc --noEmit
npm run build
# 保持本地开发服务器运行后：
node tests/smoke.mjs
node tests/access.mjs
```

`tests/smoke.mjs` 使用本地模拟账户创建临时测试记录，完成后清理。覆盖匿名访问拦截、文件写入与回读、资料/错题/组卷/成绩增删改查、题目快照隔离、分数/日期校验、跨站写入拦截。如下载目录有浏览器导出的示例卷，还会校验 DOCX 内容和分页。不要指向线上环境；测试脚本只使用本地开发 cookie。

浏览器已验证桌面与 390px 手机布局、示例选题、重排、Word 下载、成绩表单保存和刷新恢复。

## 结构与扩展点

| 文件或目录                 | 职责                                           |
| -------------------------- | ---------------------------------------------- |
| `app/workspace.tsx`        | 导航、登录后的工作台、加载状态与操作协调       |
| `components/`              | 独立的资料库、错题本、组卷、成绩分析与表单模块 |
| `lib/models.ts`            | 领域类型、科目及分类常量                       |
| `lib/validation.ts`        | 服务端写入校验                                 |
| `lib/client.ts`            | 前端 API 适配器，可替换数据后端                |
| `lib/export.ts`            | Word 文档导出，包含图片与答案分页              |
| `lib/server.ts`            | 账户身份、持久化绑定、错误处理                 |
| `app/api/v1/`              | 带版本号的 HTTP 接口                           |
| `db/schema.ts`、`drizzle/` | 数据表与追加式迁移                             |
| `.openai/hosting.json`     | 托管身份及 D1/R2 绑定                          |

后续可以独立增加 OCR 识别、自动知识点建议、间隔复习计划、计时考试等模块。新增记录种类时，在 `models.ts` 和 `validation.ts` 注册类型/校验、在聚合读取路由加入返回集合，并接入独立页面组件。OCR 可先生成错题草稿，再由用户确认后调用现有写入接口。

## API v1

配置免登录密钥后，资料与附件接口均要求有效的设备访问 Cookie，不接受仅有登录态的请求。`POST /api/v1/access` 用专属密钥换取 HttpOnly、SameSite=Lax、线上 Secure 的长期 Cookie；`GET /api/v1/access` 只返回当前设备是否已获准进入。更换密钥会让旧链接与旧 Cookie 立即失效。

个人空间沿用原 owner ID 与对象路径，无需迁移原资料。只有一个历史 owner 时才启用个人空间；若发现多个历史 owner 则拒绝自动合并。客户端不能指定所有者。所有 SQL 均绑定参数。写入操作校验同源请求；读取记录和文件不使用共享缓存。

| 方法 / 路径                        | 行为                                                          |
| ---------------------------------- | ------------------------------------------------------------- |
| `GET /api/v1/records`              | 返回当前用户的 material、mistake、paper、score、settings 集合 |
| `POST /api/v1/records/:kind`       | 新建记录；带已有 `id` 时更新，保留首次创建时间                |
| `DELETE /api/v1/records/:kind/:id` | 删除当前用户的指定记录                                        |
| `POST /api/v1/assets`              | multipart/form-data，字段名 `file`，返回附件元数据            |
| `GET /api/v1/assets/:id`           | 获取所属用户的附件；`?download` 强制下载                      |

API 错误为 `{ "error": "可显示给用户的说明" }`。401 未登录，400 校验失败，403 跨站写入，404 资源不存在。组卷写入同时保存 `questionIds`、`questions` 快照和 `points`，三者数量须一致。成绩必须满足 `0 <= score <= total <= 1000`。

存储使用 D1 的结构化记录与 R2 对象文件。附件元数据与记录分开，已上传但未被保存引用的文件可能暂存于对象存储；以后可以通过定期垃圾回收处理，回收时必须保留已保存练习卷引用的题图。现阶段避免自动清理，防止误删历史题图。

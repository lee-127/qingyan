# 清研本地版

普通 Apple 账号的 iCloud 文件同步说明见 [iCloud 文件同步](iCloud文件同步.md)。开启云盘后，在「数据与设置」连接；未连接时所有记录仍保存在本机。

双击桌面的 **「清研考研复习」** 即可打开。程序会自动启动本机服务，首次启动可能需要几秒；之后无需登录、无需 VPN，也无需联网。关机重启后仍然直接点击这个图标，不需要先运行开发命令。

资料上传、错题录入和分类、Word 组卷导出、打印 PDF、成绩记录和图表全部在本机完成。窗口右上角会显示「本地版 · 无需联网」。旧云端网址不再是桌面入口。

## 保存与备份

- 数据目录：`%USERPROFILE%\Documents\QingyanStudy\data`。记录存在 SQLite 数据库，原始资料和题图存在 `files` 文件夹。
- 程序目录：`%USERPROFILE%\Documents\QingyanStudy\app`。程序与数据分开放置，更新程序不会覆盖资料。
- 在「数据与设置」点击「导出完整备份」，会生成包含所有记录和原始文件的 ZIP。可以另存到 U 盘或其他磁盘。
- 「导入备份」会合并记录，保留本机已有的同编号记录。重复导入不会生成重复错题。
- 每天首次修改前，已有记录会自动保存数据库快照到 `data\automatic-backups`；原文件保持不可变以支持旧练习卷与恢复。
- 不要手动删除 `data` 文件夹。只关闭窗口或关闭电脑不会删除学习记录。

本地数据属于这台电脑。其他电脑需要导入完整备份；当前版本不会自动与旧云端同步。

## 启动问题

桌面快捷方式负责启动服务并打开应用窗口。重复点击会复用已运行的服务。服务只监听 `127.0.0.1`，不向局域网或互联网开放。若默认端口被其他程序占用，会自动选择备用端口。

若启动失败，会打开本机的「启动帮助」页面；详细记录保存在 `%USERPROFILE%\Documents\QingyanStudy\logs`。数据文件仍保留在上述数据目录。

## 开发与扩展

本地版复用 `app/workspace.tsx`、`components/` 与领域校验，云端版默认行为仍保留。本地入口位于 `desktop/ui/`，持久化和 API 位于 `desktop/store.ts`、`desktop/server.ts`，桌面启动逻辑在 `desktop/launcher.mjs`。

```powershell
node desktop/build.mjs
node tests/desktop-local.mjs
node tests/desktop-launcher.mjs
./desktop/install.ps1
```

构建产物为 `outputs/desktop-app`；安装会复制独立的 Node 运行时，因此日常打开软件不依赖 npm、开发服务器、项目目录或网络。

本地 API 延续 `/api/v1/records` 与 `/api/v1/assets`，另有 `/api/v1/local/health`、`/api/v1/local/info`、`/api/v1/local/backup` 和 `/api/v1/local/restore`。SQLite 使用 `user_version` 管理后续迁移。附件以 UUID 命名，并计算 SHA-256，备份导入时校验文件完整性。
